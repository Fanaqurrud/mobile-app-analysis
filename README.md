# Исследование мобильной игры

## О проекте

Проект посвящён анализу удержания игроков и оценке результатов A/B-теста в мобильной игре.

## Цель

Оценить удержание пользователей и проверить, привёл ли тестовый вариант к улучшению ключевых продуктовых метрик.

## Стек

- Python
- pandas
- NumPy
- SciPy
- Matplotlib
- Jupyter Notebook

## Что сделал

- Написал функцию для расчёта когортного retention.
- Проанализировал данные 404 770 участников эксперимента.
- Сравнил ключевые продуктовые метрики:
  - ARPU;
  - CR;
  - ARPPU.
- Проверил влияние крупных платежей на результаты эксперимента.
- Провёл статистическую проверку различий между группами.
- Предложил набор метрик для оценки игрового события.

## Результат

В тестовой группе наблюдался рост ARPU на **5,26%**, однако статистически значимого подтверждения улучшения получить не удалось.

По результатам анализа рекомендовано **сохранить текущий вариант продукта и провести дополнительную проверку**, прежде чем принимать решение о внедрении изменений.
