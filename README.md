# Исследование мобильной игры

Данный проект посвящён анализу поведения пользователей мобильной игры: расчёту retention и оценке результатов A/B-теста по ключевым продуктовым метрикам.

## Данные

В проекте используются данные о регистрациях и авторизациях пользователей, а также данные A/B-эксперимента.

В рамках эксперимента проанализированы данные **404 770 пользователей**.

## Результаты

Для анализа удержания была написана функция когортного retention.

В рамках A/B-теста сравнивались следующие метрики:

- ARPU;
- ARPPU;
- CR.

Дополнительно проверено влияние крупных платежей на результаты эксперимента.

В тестовой группе наблюдался рост **ARPU на 5,26%**, однако статистически значимых различий между группами обнаружено не было.

По результатам анализа рекомендовано **сохранить текущий вариант продукта и провести дополнительную проверку перед внедрением изменений**.

Также предложены метрики для оценки результатов игрового события.
